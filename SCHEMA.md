# Формат учебного материала ATLAS

**Версия схемы:** 0.1  
**Статус:** пилот «Машиноведение»

## 1. Принципы

- Один файл описывает одну тему или один учебный объект.
- У каждого объекта постоянный уникальный ID, не зависящий от названия файла.
- Факты, объяснения, модельно-зависимые сведения и учебные задания разделяются.
- Универсальные принципы не смешиваются с характеристиками конкретной марки техники.
- Ссылки на другие темы делаются по ID, а не по текстовому названию.
- Исходник хранится в Markdown; позднее он может импортироваться в SQLite без потери структуры.

## 2. Обязательные метаданные

Каждая статья начинается с YAML-блока:

```yaml
---
id: machine-studies.tractor.general-layout
title: Общее устройство трактора
subject: machine-studies
section: tractors
type: lesson
level: beginner
language: ru
version: 1
status: draft
updated: 2026-11-13
tags:
  - трактор
  - сельскохозяйственная техника
  - устройство машины
related:
  - machine-studies.engine.diesel-four-stroke
  - machine-studies.transmission.overview
sources:
  - SRC-FAO-2022-MACHINERY
---
```

### Поля

| Поле | Назначение |
|---|---|
| id | Постоянный уникальный ID |
| title | Название |
| subject / section | Дисциплина и раздел |
| type | article, lesson, reference, procedure, quiz |
| level | beginner, basic, advanced |
| language | Язык материала |
| version | Версия содержимого |
| status | draft, review, verified |
| updated | Дата последнего изменения |
| tags | Поисковые ключи и синонимы |
| related | ID связанных материалов |
| sources | ID источников из общего реестра |

## 3. Структура статьи

### Кратко
2–4 предложения: что это и зачем нужно.

### Назначение
Функция узла, системы или механизма.

### Устройство
Составные части. Для каждой детали — название, функция и связь с соседними узлами.

### Принцип работы
Последовательность процесса по шагам. Не пропускать причинно-следственные связи.

### Взаимодействие с другими системами
Что получает объект на входе, что передаёт на выходе, с чем связан.

### Основные понятия и параметры
Термины, величины, единицы измерения. Формулы приводить только с расшифровкой символов и единиц.

### Варианты конструкции
Отдельно описывать распространённые варианты и указывать, где именно они применяются. Не объявлять один вариант универсальным.

### Практическое значение
Пример работы на машине, роль для оператора или механика.

### Обслуживание и безопасность
Только общие безопасные принципы. Конкретные интервалы, допуски, жидкости и процедуры брать из руководства данной модели.

### Самопроверка
Вопросы и ответы либо ссылка на отдельный файл теста.

### Источники
Ссылки на первоисточники и учебную литературу с указанием применимости.

## 4. Маркировка достоверности

Использовать заметные текстовые метки:

- **Общий принцип** — справедлив для класса механизмов.
- **Типовой вариант** — часто встречается, но существуют другие исполнения.
- **Зависит от модели** — требуется руководство конкретной машины.
- **Требует проверки** — материал ещё не прошёл редакционную проверку.

## 5. Формат учебных заданий

Для теста использовать отдельный Markdown-файл с метаданными:

```yaml
---
id: machine-studies.quiz.tractor-basics-01
type: quiz
lesson: machine-studies.tractor.general-layout
level: beginner
---
```

Вопрос содержит:
- формулировку;
- тип ответа: single_choice, multiple_choice, matching, short_answer;
- варианты, если они нужны;
- правильный ответ;
- объяснение, почему ответ правильный;
- пояснение типичных ошибок.

Тест должен проверять понимание функций и связей, а не только узнавание терминов.

## 6. Источники

Реестр источников хранится отдельно в `SOURCES/sources.md`. Каждая запись получает постоянный ID, название, автора/организацию, год, ссылку, тип источника, лицензионные ограничения и список тем, для которых источник использован.

Не переносить большие фрагменты защищённых авторским правом учебников. Излагать знания самостоятельно и ссылаться на источник.

## 7. Проверка перед публикацией

- [ ] ID уникален и не меняется при переименовании файла.
- [ ] Термины используются последовательно.
- [ ] Универсальные сведения отделены от модельно-зависимых.
- [ ] Единицы измерения указаны.
- [ ] Все внешние фактические утверждения имеют источник или отмечены как требующие проверки.
- [ ] Ссылки на связанные темы ведут к существующим ID.
- [ ] Иллюстрации имеют подписи и понятные обозначения.
- [ ] Есть вопросы для самопроверки.
- [ ] Нет опасных инструкций, противоречащих руководству производителя.
