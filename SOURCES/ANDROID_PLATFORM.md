# Android platform references

## SRC-ANDROID-ROOM

- Organization: Android Developers
- Title: Save data in a local database using Room
- URL: https://developer.android.com/training/data-storage/room
- Use: local structured storage, SQLite abstraction, query validation and database migrations.
- Application to this project: store the content catalogue, bookmarks, quiz results and learning progress on-device. The app must not require a network connection to read installed content.
- Checked: 2026-11-13

## SRC-ANDROID-SQLITE

- Organization: Android Developers
- Title: Save data using SQLite
- URL: https://developer.android.com/training/data-storage/sqlite
- Use: Android SQLite fundamentals and local persistence.
- Application: reference for local offline storage. Prefer Room as the abstraction for a non-trivial structured database.
- Checked: 2026-11-13
